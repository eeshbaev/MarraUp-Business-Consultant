# MarraUp docs

## Privacy policy (Google Play)

After this folder is on GitHub, enable **GitHub Pages**:

1. Repository **Settings** → **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main**, folder: **/docs**
4. Save

Your public privacy URL will be:

```text
https://<your-github-username>.github.io/<repo-name>/privacy-policy.html
```

Use that URL in Play Console → **App content** → **Privacy policy**.

Example (replace with your username and repo):

```text
https://eeshbaev95.github.io/MarraUp/privacy-policy.html
```
